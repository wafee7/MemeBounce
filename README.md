# MEMEBOUNCE

> **"Never give up. Bounce back stronger."**

A fast-paced puzzle-platformer built with Godot 4. Every fall leaves behind an echo of your previous run that interacts with pressure plates, doors, and bounce pads to help you solve challenging levels.

---

## Features

- **8 Unlockable Characters with Unique Powers**:
  - **Froggy (The Leaper)**: +15% Jump Height (`-310.0` jump velocity)
  - **Speedy Bunny**: +32% Run Speed (`122.0` speed)
  - **Spore Bouncer**: Floaty spore descent with soft gravity (`620.0`)
  - **Sigma Detective**: Coin Magnet (auto-attracts coins within 54px) & **2× Coin Multiplier**
  - **Terrible Knight**: Titan Stomp with boosted bounce velocity (`-430.0`)
  - **Cyber Marine**: Jet Thrust In-Air **Double Jump**
  - **Valkyrie Heroine**: Air Dash (press **Shift** or **C** in mid-air)
  - **Grotto Lizard**: Wall Scaler (Wall Slide & Wall Kick)
- **7 Handcrafted Levels** with progressive difficulty and unlock progression.
- **Echo Mechanic**: Your failed attempts record your trajectory and replay simultaneously to solve cooperative puzzles solo.
- **Coin & Trade Economy**: Collect golden coins scattered throughout levels to unlock heroes in the Main Menu shop.
- **Level Select**: Dynamic level select modal with stage titles and status tracking.
- **Comic Book "How to Play" Manual**: Interactive guide detailing mechanics and heroes.

## Controls

| Action | Key / Input |
|---|---|
| **Move Left / Right** | `A` / `D` or `Arrow Keys` |
| **Jump** | `Space` or `W` or `Up Arrow` |
| **Rebound / Fast Reset** | `R` |
| **Air Dash** *(Heroine)* | `Shift` or `C` |
| **Double Jump** *(Marine)* | Press `Space` in air |
| **Wall Jump** *(Lizard)* | Slide against wall + `Space` |
| **Pause / Back** | `Escape` |

## How to Run

### Using Godot Engine 4 (Recommended)
1. Open Godot 4 (v4.3 or v4.7+).
2. Click **Import** and select `source/decompiled_full/project.godot`.
3. Press **F5** or click **Run Project**.

Or double-click `Open_In_Godot.bat` in the root folder.
